Code accompanying [InsurTech Innovation Using Natural Language Processing](/publication/insurtech-nlp).

The repository implements:

- Lexicon-based sentiment analysis to de-bias customer star ratings with objective polarity scores
- Neural embedding of 13,000+ raw business categories into compact 24-dimensional context-aware features
- Unsupervised topic modeling for automated NAICS industry classification

Available at: [https://github.com/PanyiDong/InsurTech_NLP](https://github.com/PanyiDong/InsurTech_NLP)
